# ☕ Menú de Café - Proyecto freeCodeCamp

¡Hola! 👋 Bienvenido/a a este repositorio.

Este proyecto forma parte de mi proceso de aprendizaje en desarrollo web. Aquí estoy rehaciendo y practicando los proyectos y talleres del módulo de **HTML y CSS** de la certificación *Responsive Web Design* de **freeCodeCamp**.

---

## 🎯 Objetivo del Repositorio

* **Reforzar HTML & CSS**: Rehacer el proyecto del *Menú de Café* desde cero en **Visual Studio Code** para afianzar maquetación, estilos, Flexbox y diseño responsivo.
* **Dominar Git & GitHub**: Utilizar este proyecto para aprender el flujo de trabajo con control de versiones en la terminal (Git Bash) y la sincronización con GitHub (`git add`, `git commit`, `git push`, gestión de repositorios, etc.).
* **Construir bases sólidas**: Prepararme técnicamente para encarar los siguientes módulos de Desarrollo Web Full Stack (como JavaScript).

---

## 🛠️ Tecnologías y Herramientas Usadas

* **HTML5**: Estructura semántica.
* **CSS3**: Estilos y diseño visual.
* **Visual Studio Code**: Editor de código.
* **Git & Git Bash**: Control de versiones local.
* **GitHub**: Repositorio remoto en la nube.

---

## 🚀 Lo que estoy aprendiendo

1. Inicialización de repositorios con `git init`.
2. Manejo del *Staging Area* y creación de *commits* limpios.
3. Conexión de repositorios locales con GitHub (`git remote`) y uso de *tokens* de seguridad.
4. Sincronización continua con `git push`.
