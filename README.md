* **Desarrollo Web Responsive**: Reforzar maquetación semántica, diseño adaptable, Flexbox y CSS Grid escribiendo el código desde cero en **Visual Studio Code**.
* **Control de Versiones (Git & GitHub)**: Practicar el flujo de trabajo en la terminal (Git Bash), gestión de ramas, organización mediante un repositorio contenedor y buenas prácticas con *Conventional Commits*.
